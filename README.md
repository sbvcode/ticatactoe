# Tic Tac Toe Android App

A simple Android Tic Tac Toe game built with Jetpack Compose and Material 3.

## Features
- Two-player hot seat gameplay on a 3x3 grid
- Highlights for X and O moves with different colors
- Automatic detection of wins and draws
- Reset button to quickly start a new round

## Getting Started
1. Open the project in **Android Studio Flamingo (2022.2.1)** or newer.
2. When prompted, let Android Studio download the required SDK components.
3. Sync the Gradle project.
4. Choose an emulator or a connected Android device running API level 24 or higher.
5. Click **Run** to install and launch the app.

## Project Structure
- `app/src/main/java/com/example/tictactoe/MainActivity.kt` – Compose UI and game logic.
- `app/src/main/res/values/` – String, color, and theme resources.
- `app/src/main/AndroidManifest.xml` – Application manifest.

Feel free to extend the app with animations, AI opponents, or score tracking!
